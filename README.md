## Run
1. Keep your existing `.env` file in this folder (replace the placeholder values in the included `.env` with your real Gmail/App Password if needed).
2. Open Terminal in this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open http://localhost:3000

Signup/login are server-backed using `users.json`. Do not share `.env` or your Google App Password.
